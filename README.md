# RSVP w/ me

Public tools for [RSVP w/ me](https://rsvpw.me).

- [`rsvp-skill/`](rsvp-skill/) — the skill and MCP server setup that let your AI assistant (Claude, Claude Code, ChatGPT/Codex, Gemini CLI) search events and, on the paid plan, see your plans and friends. Install steps are in its [README](rsvp-skill/README.md).

Quick install for Claude Code:

```
/plugin marketplace add turoczy/rsvpwme
/plugin install rsvpwme@rsvpwme
```
