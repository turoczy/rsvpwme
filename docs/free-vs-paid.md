# Free vs paid

Free is $0 forever. No credit card required.

The paid plan is called **Attendee**. It's $9.99 + tax, one time. Pay once. That's it. No subscription.

| | Free | Attendee (paid) |
|---|---|---|
| Browse events, Like, mark Going | ✓ | ✓ |
| Profile | Private or Anonymous | Public, Private or Anonymous |
| Your own @handle and public page | | ✓ |
| Show up when people search for you | | ✓ (you can opt out) |
| Follow people | Up to 3. New members who join through your invite link don't use a spot. | As many as you like |
| New followers | You approve each one | A public page can auto-approve |
| Invite friends to events | ✓ | ✓ |
| Follow event tags | | ✓ |
| Close friends | | ✓ |
| Private calendar feed | | ✓ |
| Add events to the site, one at a time | | ✓ |
| Weekly email | Your week, plus what your friends are going to | Also what your friends Liked |
| Connect your AI | Search events. Keep 2 apps connected. | Also your plans and friends, and Liking. Keep up to 25 apps connected. |
| Paid check by your name | | ✓ |

A few early accounts got an @handle before there was a paid plan. They keep it, their page is private, and they show up in people search like a paid account (and can opt out the same way).

## Buying it

Go to [rsvpw.me/pricing](https://rsvpw.me/pricing). Payments are processed by Stripe, and your receipt comes from Stripe. Sales tax is added at checkout where it applies.

Refunds go through Stripe, under its refund policy. The [Terms](https://rsvpw.me/terms) have the details.
