# Adding events (paid)

We keep an eye on a set list of calendars and groups, so the River keeps growing on its own. Paid accounts can also add events on the fly, one at a time.

On a free account, My events shows "Want to add events to the list? Upgrade" instead. See [Free vs paid](free-vs-paid.md).

## Paste a link

At the top of **My events**, paste any event link (Luma, Meetup, Eventbrite, Partiful, or any event page) and click **Add**.

Say a friend texts you a Meetup link for a Thursday night meetup that isn't on the River. Paste it, click **Add**, and you land on **Check the details**: what we pulled from the page, every field editable. Fix anything that's off (a wonky title, a missing start time) and click **Add to RSVP w/ me**.

- Adding an event Likes it for you, so it lands on your list.
- Events you add are public on RSVP w/ me. They show up for everyone, like any other listing. Your name isn't shown publicly as the person who added it.
- One event at a time. Paste a page that lists several events and we'll say "That page lists 6 events. Open the one you want and paste its link."
- Already have it? You'll see **We've already got that one** with a **Go to event** button. Like it or say Going from there.
- Can't read the page? You'll see **Couldn't add this event** with the reason. Click **Add it manually** and type it in yourself. Only the title and start time are required.
- Facebook and LinkedIn events don't work by pasting. We don't open those pages. Open the event in your browser and use the bookmarklet below.

Sometimes an event shows as **Pending** for a bit. We're double checking to make sure this event isn't a duplicate. Once added, it'll be in your Likes. If it's already here, we add you to it instead, and it's in your Likes too.

## The bookmarklet

Paid accounts get a button for adding events from just about any event site.

1. On **My events**, find **Add events from anywhere**.
2. Drag the **🗓️ Add to RSVP** button to your browser's bookmarks bar. It runs from there, not from the My events page. Clicking it there shows a how-to instead.
3. On any event page (Luma, Eventbrite, Meetup, Calagator), click it. You get the same **Check the details** page, then **Add to RSVP w/ me**.

It also works on pages we can't open ourselves, like Facebook and LinkedIn events, because it uses what your browser already sees. Those sometimes leave out the start time, so check it before you add.

## Good to know

- Links in events you add are checked against Google's list of unsafe sites. Only the link is sent to Google.
- If you delete your account, events you added stay listed. The record that you added them is removed.
